プライバシーポリシー

最終改定日: 2026年11月9日

1. アプリと運営者

このプライバシーポリシーは、アプリ「doublestandard-log-mcp」（以下「本アプリ」）に適用されます。本アプリは運営者個人が自身のYouTubeチャンネル運用のためにのみ使用するもので、一般には公開・配布していません。連絡先: aicreater747@gmail.com

2. 使用するサービス

本アプリは YouTube API サービスを使用します。本アプリの利用には YouTube 利用規約 が適用され、Google によるデータの取り扱いについては Google プライバシーポリシー をご確認ください。

3. アクセスするデータと目的

本アプリは、運営者本人のYouTubeチャンネルについてのみ、動画メタデータ（タイトル・説明・タグ等）の取得と編集、および動画の非公開アップロードを行います。それ以外の目的でデータを取得・利用することはありません。

4. データの保存

OAuth アクセストークンおよびリフレッシュトークンは、運営者のローカル環境にのみ保存します。APIを通じて取得したデータを外部サーバーに保存・蓄積することはありません。

5. 第三者への共有・利用制限

取得したデータを第三者と共有することはありません。広告目的での利用、データの販売、AIモデルの学習への利用も行いません。本アプリは Google API サービスのユーザーデータに関するポリシーの Limited Use（利用制限）要件に準拠します。

6. データの削除とアクセス権の取り消し

保存されたトークンは運営者がいつでも削除できます。また、Google アカウントの権限ページ から、本アプリへのアクセス権をいつでも取り消すことができます。

7. ポリシーの改定

本ポリシーを改定した場合は、このページで告知します。
